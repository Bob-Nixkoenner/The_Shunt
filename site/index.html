The Shunt

Choose per app which VPN tunnel it uses. WireGuard on Linux, Windows and Android, OpenVPN on Linux and Android, Tailscale/Headscale on Linux and Windows, with a kill switch that blocks instead of leaking. Built-in Tor and SOCKS exits (Android: built-in Tor in the GitHub APK), a DNS filter, and three levels from Simple to Max Security with an optional network defense. English and German. Open source, no account, no telemetry. You bring your own servers.

Deutsch: Wähle pro App, welcher VPN-Tunnel genutzt wird. Kill-Switch, DNS-Filter, Tor und SOCKS-Ausgänge und drei Stufen von Einfach bis Max. Sicherheit mit optionaler Netzwerk-Abwehr. Deutsch und Englisch. Quelloffen, ohne Konto und ohne Telemetrie. Eigene Server werden selbst eingetragen.

Get it

  • Linux: install.sh from the README (Debian, Ubuntu, Arch, Fedora and relatives).
  • Windows 10/11: the Setup.exe from the releases.
  • Android: APK from the releases.
